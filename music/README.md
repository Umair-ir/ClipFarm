# Music library

Put licensed music here. **Each track needs a sidecar `.yaml` with the same name**, or ClipFarm
won't use it:

```
music/
  neon-run.mp3
  neon-run.yaml
```

```yaml
title: Neon Run
artist: Some Artist
license: CC-BY-4.0          # required: CC0, CC-BY-4.0, royalty-free, owned, ...
source: https://...         # where the track and its license came from
attribution: "Music: Neon Run by Some Artist (CC BY 4.0)"   # optional; added to video descriptions
moods: [hype, energetic]    # used by automatic selection (see music_moods in config/edit.yaml)
```

The easiest way is the CLI, which copies the file, writes the sidecar and analyzes the beats:

```bash
python -m clipfarm music add ~/Downloads/neon-run.mp3 --license CC-BY-4.0 \
  --source https://... --moods hype,energetic --attribution "Music: Neon Run by Some Artist (CC BY 4.0)"
python -m clipfarm music list
```

## Where to get music you're allowed to use

- **YouTube Audio Library** (YouTube Studio → Audio Library): free for YouTube videos; some tracks require attribution.
- **Pixabay Music**, **Free Music Archive** (filter by CC license), **Incompetech** (CC-BY, attribution required).
- Music you made or bought a license for.

Trending or commercial songs aren't safe even if other Shorts use them: YouTube's Shorts
music picker licenses them only inside the app. Uploading them in your own file will get claimed.

`sample_beat_128bpm.wav` is an original test beat generated by `tests/make_sample_music.py`.
Delete it once you've added real tracks.
